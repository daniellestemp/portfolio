Visualizing Decades of Labor Data in Tableau Dashboards

Curious about the evolution of U.S. labor unions, I wondered whether there was a better way to view and interact with historic labor and employment data — and built an interactive Tableau dashboard to find out.

01 · Challenge

The central challenge was visualizing hundreds of data points without overwhelming the viewer — choosing the right visualization types and tools would be key.

02 · Solution

An interactive Tableau dashboard visualizes the historic labor and employment data, paired with a separate static dashboard that zooms into specific snapshots to illustrate micro trends. R's geographic libraries added a mapped layer of key labor and economic variables for further context.

Left: users can select a state to view membership rates over time (dashboard ↗). Right: a static snapshot contrasts the steady pre-pandemic trend with more volatile membership and employment shifts around COVID-19 (dashboard ↗).

03 · Process: An Iterative Approach

  • Start broad: explore union-specific data for historical patterns, relationships, and outliers.
  • Employ best practices: lean on visualization techniques that communicate general trends clearly.
  • Zoom in: dig into sector-level data for micro trends in membership and employment.

Peer review and user testing then shaped revisions — feedback flagged the heat map's color scheme and key as hard to interpret, and pointed out that it wasn't always clear how stacked vs. side-by-side line graphs were meant to be read.

04 · Reflections

  • Exploratory analysis is essential: understanding and cleaning the data structure has to happen before opening Tableau or R.
  • User testing matters: incorporating outside perspectives improved the visualizations well beyond what a single point of view could catch.
  • Data-driven vs. story-driven: with so much existing narrative around this topic, it took discipline to let the data lead rather than the other way around.
